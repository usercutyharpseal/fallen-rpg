# 몰락자 v0.9.22

## 직업 선택 삽화 UI 조정
- 직업 초상 원본 2:3 비율을 보존하는 세로 프레임으로 변경
- 기존 132px 가로 배너형 `object-fit: cover` 제거
- 모바일 직업 카드는 `세로 삽화 / 정보` 2열 레이아웃
- 스탯은 좁은 화면에서 2x2, 넓은 화면에서 4열
- 직업 삽화는 `object-fit: contain`으로 투구·무기·의상 잘림 방지
- 인게임 장면 삽화 구조는 그대로 유지

기존 v0.9.21의 악마의 제의, 노예 엔딩, 직업별 삽화, PVP, 팬텀, 도박꾼 등 기능은 유지됩니다.
