# 몰락자 — Normal Mode v0.9.3

## v0.9.3 — Verified Permanent Ranking
- Supabase 저장 성공 후 서버가 같은 행을 다시 조회해 검증
- 브라우저도 /api/player 재조회로 영구 기록을 한 번 더 확인
- DB 실패/로컬 백업은 절대 등록 성공으로 표시하지 않음
- 엔딩 화면에 이번 점수/영구 최고점/현재 순위/저장 상태 표시
- 낮은 점수는 최고기록을 유지하되 닉네임은 갱신 가능
- 랭킹 창에서 내 영구 최고기록과 내 행을 강조 표시
- 대기 기록은 실제 영구 저장 검증이 끝난 경우에만 큐에서 제거

- 같은 인물도 루트가 다르면 별도 배드엔딩 (친위대장/세리아 등)
- 사망 장면의 기존 삽화를 엔딩 화면에 재사용
- 사망 장소/원인/배드엔딩 보정 점수 표시
- 고유 배드엔딩 제목이 랭킹에도 저장됨
- 후반 강적 사망은 난이도에 따른 소량 점수 보정

모바일 우선 텍스트 RPG 프로토타입.

- 스토리 분기형 노말 모드
- 기사 / 귀족 / 도둑 초기 해금
- 대화 / 공격 / 처세 / 도망 + 조우 아이템
- 다단계 대화에 따른 판정 변화
- 승률 기반 전투 + 패배 시 D6 역전 판정
- 성장 이벤트 / 상점 / 저장 후 나가기
- BAD END 및 다중 엔딩
- 최고점 랭킹 / Supabase 영구 저장 지원
- Render 공개 배포 설정 포함

로컬 실행: `npm install && npm start`
