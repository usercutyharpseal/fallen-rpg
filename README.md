# 몰락자 v0.9.20

## 핵심 변경
- 신규 해금 직업 `도박꾼` 추가: 체력 5 / 공격 4 / 처세 4 / 속도 2
- 해금 조건: 노말 성공 엔딩 1회
- `운세가 좋군`: 처세 성공마다 1~6 중 한 눈을 무작위 강화. 중복 눈은 재추첨 없이 꽝
- 역전 주사위가 강화 눈에 멈추면 즉시 역전
- 노말 모드도 SOLO / PVP로 분리
- PVP는 기존 노말 스토리를 양쪽이 동시에 플레이하고 최종 점수로 승패 판정
- 실시간 상대 점수/진행도 표시
- PVP Elo 레이팅 1000 시작, TOP 50 랭킹
- 경기 제한시간 30분, 연결 끊김 20초 재접속 유예
- PVP 세이브와 SOLO 세이브 분리
- 망령사 망령 버프
- 처세 보상 강화: 성공 점수/골드/고난도 협상 보너스

## 망령
- 일반 적: 공격 승률 +18%, 적 공격력 -4
- 보스급: 공격 승률 +14%, 적 공격력 -3
- 최대 체력 8 초과분 2당 공격 승률 +1%, 최대 +5%

## 처세 보상
- 처세 성공 300점
- 대화 해결 210점
- 성공확률 45% 이하 처세 성공 시 추가 500점
- 상대 처세 난이도 기반 골드 획득
- 귀족은 협상 골드 1.5배

## PVP
- Socket.IO 실시간 매칭
- 기존 76개 장면 노말 스토리 그대로 사용
- 양쪽 모두 끝나면 점수 비교
- 동점: 진행도 > HP > 골드 순
- Elo K=32
- PVP 레이팅은 Supabase `fallen_scores`에 별도 레코드로 저장

## 도박꾼
- 스탯: 5 / 4 / 4 / 2
- 강화 눈은 한 런 동안 유지되며 세이브/이어하기에 보존
- 이미 강화한 눈이 다시 나오면 강화 기회가 그대로 소모됨
- 기본 6 성공 및 행운의 동전 5~6 성공과 강화 눈 판정을 합산
- HUD/결과창에서 강화 눈, 실질 강화 역전, 중복 꽝 확인 가능
