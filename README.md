# 몰락자 v0.9.21

## 이번 버전
- 기존 추상 SVG 삽화를 AI 고전 다크 판타지 삽화로 교체
- 장면 삽화 18종 + 직업 초상 8종을 WebP 자산으로 분리
- 8개 직업 선택 카드에 전용 초상 추가
- 인게임 장면 삽화에 현재 직업 초상을 겹쳐 표시하여 주인공 외형을 구분
- 주요 엔딩도 실제 삽화 사용
- 악마의 제의 이벤트 추가
  - 능력치 하나가 15 이상이 되면 게임 중 1회 출현
  - 거래 수락: 해당 능력치 +5, 최종 엔딩은 숨겨진 `노예`
  - 긍지: 공격/처세/속도 -4, 엔딩 보너스 x1.5
  - 무시: 변화 없음
- 노예 엔딩 보너스 6,500
- 클라이언트/서버 점수식의 긍지 보너스 일치

## 삽화 구조
- `public/assets/art/*.webp` : 장면/엔딩 삽화
- `public/assets/classes/*.webp` : 직업 초상
- `ART_FILES` : 기존 장면 art 키와 실제 파일 매핑
- `CLASS_ART_FILES` : 직업 id와 초상 파일 매핑

추가 삽화를 넣을 때는 WebP 파일을 추가한 뒤 `ART_FILES`에 한 줄만 연결하면 된다.
