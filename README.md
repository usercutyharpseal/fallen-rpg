## v0.9.2 — Contextual BAD END
- 전투 가능한 26개 조우마다 고유 배드엔딩 제목/후일담 적용
- 같은 인물도 루트가 다르면 별도 배드엔딩 (친위대장/세리아 등)
- 사망 장면의 기존 삽화를 엔딩 화면에 재사용
- 사망 장소/원인/배드엔딩 보정 점수 표시
- 고유 배드엔딩 제목이 랭킹에도 저장됨
- 후반 강적 사망은 난이도에 따른 소량 점수 보정

모바일 우선 텍스트 RPG 프로토타입.

- 스토리 분기형 노말 모드
- 기사 / 귀족 / 도둑 초기 해금
- 대화 / 공격 / 처세 / 도망 + 조우 아이템
- 다단계 대화에 따른 판정 변화
- 승률 기반 전투 + 패배 시 D6 역전 판정
- 성장 이벤트 / 상점 / 저장 후 나가기
- BAD END 및 다중 엔딩
- 최고점 랭킹 / Supabase 영구 저장 지원
- Render 공개 배포 설정 포함

로컬 실행: `npm install && npm start`
