# 몰락자 Normal Mode v0.9.8

## v0.9.8 핵심
- 죽은 NPC가 이전 장면 재진입으로 되살아나는 현상 차단
- 한 번 끝난 조우를 처세/도망으로 반복 파밍하는 현상 차단
- 처세/도망 사용 횟수를 장면이 아니라 조우 단위로 유지
- 구버전 세이브의 주요 사망 플래그를 새 세계 상태로 자동 이관
- 잘못된 재진입 때만 등장하는 장의사 모르텐 / 추적자 리안 추가
- 같은 현상을 다시 시도하면 빈 무덤/끊긴 흔적 연출로 대체
- 과거 장면 재진입으로 진행도 점수를 반복 획득하는 문제 차단
- 살아 있는 동일 인물의 훗날 정상 재등장은 허용
