# 몰락자 v0.9.19

## 핵심 변경
- 노말 모드도 SOLO / PVP로 분리
- PVP는 기존 노말 스토리를 양쪽이 동시에 플레이하고 최종 점수로 승패 판정
- 실시간 상대 점수/진행도 표시
- PVP Elo 레이팅 1000 시작, TOP 50 랭킹
- 경기 제한시간 30분, 연결 끊김 20초 재접속 유예
- PVP 세이브와 SOLO 세이브 분리
- 망령사 망령 버프
- 처세 보상 강화: 성공 점수/골드/고난도 협상 보너스

## 망령
- 일반 적: 공격 승률 +18%, 적 공격력 -4
- 보스급: 공격 승률 +14%, 적 공격력 -3
- 최대 체력 8 초과분 2당 공격 승률 +1%, 최대 +5%

## 처세 보상
- 처세 성공 300점
- 대화 해결 210점
- 성공확률 45% 이하 처세 성공 시 추가 500점
- 상대 처세 난이도 기반 골드 획득
- 귀족은 협상 골드 1.5배

## PVP
- Socket.IO 실시간 매칭
- 기존 76개 장면 노말 스토리 그대로 사용
- 양쪽 모두 끝나면 점수 비교
- 동점: 진행도 > HP > 골드 순
- Elo K=32
- PVP 레이팅은 Supabase `fallen_scores`에 별도 레코드로 저장
